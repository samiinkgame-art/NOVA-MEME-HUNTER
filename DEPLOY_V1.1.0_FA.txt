NOVA MEME HUNTER V1.1.0 — APEX EDGE

BACKEND
1) در Repo بک‌اند NOVA-MEME-HUNTER فایل‌های این پوشه را جایگزین/آپلود کن.
2) app.py، requirements.txt و Dockerfile حتماً در ریشه Repo باشند.
3) Northflank با CI/CD باید Commit جدید را Build/Deploy کند. اگر نکرد، Redeploy بزن.
4) Environment Variableها:
   NOVA_ADMIN_KEY = همان مقدار خصوصی فعلی
   PUMPPORTAL_API_KEY = همان کلید فعلی
   PUMPPORTAL_TRADE_STREAM_ENABLED = true
5) Port همان 8000 / HTTP / Public بماند.
6) بعد از Deploy آدرس /health را باز کن.
